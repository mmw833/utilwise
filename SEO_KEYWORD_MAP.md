## 영어 페이지 원칙

- 영어 URL은 영어권 검색 의도에 맞춘 독립 title, description, H1, 본문을 사용한다.
- 한국의 법률·세금·급여·부동산 제도를 계산하는 영어 페이지는 South Korea / Korean rules를 명시해 적용 국가를 혼동하지 않게 한다.
- 한국어·영어 대응 페이지에는 alternates.languages를 연결하고 각 페이지의 canonical은 자기 URL을 가리키게 한다.
- 영어 페이지의 검색어는 번역만 하지 않고 실제 영어 검색 표현(예: pyeong converter, take-home pay calculator, severance pay calculator)을 반영한다.

## 콘텐츠 및 색인 정책

1. 대표 검색어는 페이지당 하나의 핵심 주제로 유지하고, 보조 검색어는 제목·설명·본문에 자연스럽게 반영한다. 검색어를 반복 삽입하지 않는다.
2. 각 계산기 페이지에는 입력 도구 외에 계산 공식, 계산 예시, 자주 묻는 질문, 적용 범위·한계, 신뢰할 수 있는 공식 출처와 기준 확인일을 둔다.
3. 법령·세금·보험료·금융 규정에 영향을 받는 계산기는 수치와 출처를 정기적으로 확인한다. 기준 확인일을 임의로 갱신하지 않는다.
4. 텍스트 도구는 실제 처리 방식(줄 단위 비교, 공백 구분 단어 수, 문장 경계 규칙 등)을 설명해 사용자가 결과의 범위를 이해하게 한다.
5. 심리·성격 테스트 소개 페이지는 색인 대상. 문항 진행 페이지와 개인별 결과 화면은 noindex,follow를 유지한다. 공개적으로 유용한 고정 결과 설명 페이지만 별도 검토 후 색인한다.
6. 개인정보처리방침·이용약관은 신뢰와 안내를 위해 제공하되, 주요 검색 유입 랜딩 페이지로 취급하지 않는다.
7. 사이트맵에는 canonical이 자기 자신인 공개 랜딩 페이지만 포함한다. noindex 화면, 임시 화면, 중복 URL은 포함하지 않는다.
8. 실제 검색 유입 개선은 Google Search Console과 네이버 서치어드바이저의 페이지별 노출수·클릭수·검색어를 기준으로 판단한다. 색인 등록만으로 노출이나 순위를 보장하지 않는다.

## 다음 SEO 검증 작업

- Google Search Console: 페이지 색인 생성, 크롤링된 페이지, 검색어별 노출·클릭·평균 게재순위 확인
- 네이버 서치어드바이저: 수집 현황, 색인 현황, 사이트 진단, 사이트맵 제출 상태 확인
- 주요 페이지별 검색 결과 title/description 실제 표시와 canonical 선택 확인
- 모바일 Core Web Vitals 및 실제 사용자 경험 확인
- 법률·세금·금융 계산기 공식 출처와 기준일 분기별 확인
