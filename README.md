# UTILWISE starter

UTILWISE 초기 홈페이지 및 계산기 5종의 Next.js 프로젝트입니다.

## 포함된 기능
- 반응형 홈 화면
- 평수·면적 변환
- 대출 원리금균등 / 원금균등 계산
- 주택 매매·임대차 중개보수 상한 추정
- 연봉 실수령액 간이 추정
- 퇴직금 추정

## 로컬 실행
1. Node.js LTS 설치
2. 압축 해제 후 이 폴더에서 터미널 실행
3. `npm install`
4. `npm run dev`
5. 브라우저에서 `http://localhost:3000` 접속

## Cloudflare 배포
Cloudflare Workers + OpenNext 어댑터를 사용하도록 기본 구성을 포함했습니다.
Cloudflare 계정 연결 및 실제 배포 전 최신 공식 가이드에 따라 설정을 검증해야 합니다.

## 중요 계산 안내
- 중개보수는 주택 기준 기본 상한요율의 초기 구현입니다. 지자체 조례, 물건 종류, 거래 유형별 차이를 추가 검증한 후 공개해야 합니다.
- 연봉 실수령액은 4대 보험 및 소득세를 단순 추정합니다. 국세청 근로소득 간이세액표 전체를 반영한 공식 세액 계산기가 아닙니다.
- 퇴직금은 입력한 급여와 재직일수에 따른 단순 추정이며, 법정 평균임금 산정의 모든 예외를 반영하지 않습니다.
- 실제 공개 전 각 계산기의 공식·법령·예외조건을 검증하고, 출처 및 최종 업데이트 날짜를 표시하세요.
